**Fig. X | Architecture and tiled dataflow of the FlashAttention accelerator.**
A 128-bit tile loader assembles two input beats into each 256-bit Q/K/V cache word, exposing 32 INT8 lanes per cycle from ping-pong banks. The QK/PV engines sign-extend those lanes to the PE's 16-bit registered operands. A shared 32 x 32 output-stationary systolic array, implemented as four 8-row physical stripes, alternates between QK score generation and beta-V accumulation. Each PE reuses one mode-select arithmetic datapath for `acc + a*b`, subtraction, signed maximum pass-through, addition, and scale-shift operations; MAC and HOLD update the local accumulator while the other modes return a result. The online softmax unit applies scaling and masking, updates the row-wise `(m, l)` state, and produces `alpha` and `beta` without materializing score or probability tiles in off-chip memory. The output accumulator rescales the prior partial result by `alpha` across K/V tiles; reciprocal normalization and requantization then produce INT8 rows for the 128-bit AXI4 writeback interface. Solid teal paths denote data movement, magenta paths denote online-state feedback, and dashed amber paths denote scheduler control.
