## 单层主图的单位

- 输入来自30步真实采样轨迹，固定步索引15、seed301、条件分支 B=1。
- PixArt-Sigma 固定层索引14，H16/d72；Wan2.1 固定层索引15，H12/d128。
- 这些位置在测试前固定，用于控制层/步变化后观察 N 扩展；一个位置不是全模型代表性证明。
- 每个点执行该调用的全部 head 和全部 N 行，计算 QK、softmax、PV。
- GPU 为 FP16 显存驻留 SDPA。20次预热、3×30次重复是同一 Q/K/V 的计时样本，
  不是30个扩散步，也不是90次独立生成。
- ASIC 为当前 INT8 RTL，统计一次完整多头 job 的 START 到最后输出 B 握手；
  包含 loader、KV重读、等待与 drain，排除 reset/寄存器预配置/离线量化打包。
- ASIC ms=实际周期×1.60ns。625MHz是综合目标，输入为理想128-bit服务，不是硅片实测。

## 全部层补测

- 为避免只凭一个中间层进行外推，补测两模型在 N1024 与 N4096、步索引15的全部 self-attention 层。
- 已重新采集同一 prompt/seed 的真实轨迹；中间层 Q/K/V 必须逐元素等于主图原向量。
- 每层使用该层独立校准后冻结的 scale，完整 H/N/d，不裁 token、head 或 feature。
- GPU 对显存驻留的全部层 Q/K/V 顺序执行 SDPA，实测累计 CUDA-event 时间；
  这是一组捕获算子的顺序回放，未在回放期间重新生成层间 hidden states。
- ASIC 分别回放每层真实张量；只在28/30个 job全部通过后，累加实际周期。
  不用一个中间层周期乘层数，不把某个 head 的时间乘 head 数。
- 该结果叫“指定步全部层的累计 SDPA 时间”。不包含投影、cross-attention、MLP、
  normalization、scheduler、另一 CFG 分支等，不能命名为“完整扩散时间步延迟”。
- N1024是流程验证；N4096是正式跨层点，对应PixArt 1024²图像和Wan 512²/13帧视频。
- 长 N 的主图仍逐点实测；不把该全层测试
  宣称为 N16384 所有层/所有采样步都已经验证。

## 论文中的放置

- Introduction：profiling提出瓶颈，随后明确硬件目标是SDPA，非整个self-attention模块。
- Evaluation：先写计时单位、固定层/步的理由与局限，再写全部层覆盖、机制对照和PPA范围。
- 主图 caption：单层、完整多头 SDPA；GPU FP16 与 ASIC INT8/目标时钟需可见。
- 结论：仅归纳有对应测量支持的硬件结论；完整生成收益留待真正的集成实验。

数值精度仍按用户决定先作诊断。功能全等只说明符合当前定点算术，不等价于生成质量达标。
