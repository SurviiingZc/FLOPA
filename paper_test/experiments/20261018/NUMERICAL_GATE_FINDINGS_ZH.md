# 真实模型数值放行结果与修正建议

日期：2026-10-18。本报告使用已冻结校准与误差门槛，未调宽门槛、未更换失败seed。
它是按Evaluation计划第5节执行的D1结果；不是已完成的投稿性能结论。

## 1. 真实输入与结论

- 模型：PixArt-Sigma，同一1024-MS checkpoint；实际输入512×512像素。
- SDPA：B=1，H=16，N=1024，d=72；真实30步去噪轨迹，seed301，layer14/step15。
- 输入来自Q/K/V投影之后的SDPA边界；完整16个head、全部query与KV均经过整数shadow。
- 独立校准：seed1001/1002、不同提示词、N=1024/16384、所有层和step的maxabs。
- 10/16个head未通过相对L2≤5%门槛；相对L2范围3.60%–7.72%，最低cosine约0.99771。
- Q/K/V裁剪计数均0；PV/O溢出计数0；输出饱和计数0。

因此，**当前算术格式尚不能直接用于该真实模型的已放行性能图**。
没有溢出不能替代误差检查；也不能把短UVM逐字节通过等同于FP32模型精度通过。

### 2.1 软件counterfactual已补充（不是RTL结果）

保持同一PixArt输入、校准参数、tile顺序与原INT32范围不变，分别替换指数近似后：

- 仅P使用理想指数，alpha保持原实现：精确除法下总误差最大4.96%。
- 仅alpha使用理想指数，P保持原实现：精确除法下总误差最大3.07%。
- P与alpha均用理想指数：精确除法下总误差最大2.66%。
- P与alpha改为32段线性指数，并用256项倒数种子、保留exponent到乘法后：
  包含原INT8输出舍入后，16个head总误差为1.95%–4.30%。

这组诊断说明，粗分段alpha在跨KV tile反复作用时值得优先修正。
32段/256种子的结果仅为已失败向量上的软件设计验证，不是独立留出测试，
更不是已实现RTL、面积或能效收益；N16384等还需分别验证。

## 3. 长N范围压力测试

未修改RTL的VCS单PE回放与宽位数参考一致：P=32767、每32个token按alpha=32767
重缩放时，V=-128在第513个token首次回绕，V=127在第517个token首次回绕。
已运行到N=16384。PASS表示成功复现限制，不表示这些压力输入数值正确。

这是合法INT8域的压力例，不意味着上述真实PixArt输入已经溢出。真实最长N的评估
向量仍需专门验证，不能用压力例直接替代实际模型结果。

分析上，若完全保留P16×V8、不在乘积前后缩放，N≤16384的最坏同号累加至少需要
37位有符号O；若要覆盖16位序列寄存器的全部N≤65535，则至少需要39位。
这属于范围推导，不是已经实现的硬件或PPA结果。QK的32位范围与此问题分开处理。

## 4. 建议的修正顺序（尚未改RTL）

1. 先做软件counterfactual：分别改变PWL、alpha精度、倒数表示，保持当前输入、scale、
   tile顺序不变，确定是哪一项使5个head在精确除法下仍失败。
2. 候选方案为更细的分段指数，以及保留倒数mantissa/exponent直至乘法后再移位。
   先验证准确性，再决定32段等具体参数；不能把候选参数写成已验证结论。
3. 在最长真实N上检验O范围。若需修正，比较分离QK/PV累加位宽与受控PV定点缩放，
   分别记录准确性、SRAM宏映射和总PPA；不预先声称扩位或移位没有成本。
4. 保持32×32阵列、P本地驻留、runtime-d、QKV feature-major布局和主体数据流。
   数值修改通过短RTL验证与独立留出向量后，再重新综合并绑定新PPA。
5. 校准仍与测试分离。保留本次失败seed301作为诊断；增加401/402/403作为新的
   留出正确性检查，不能只挑修正后通过的head、长度或seed。

主稿Architecture主体暂未改动。将来若指数段数、累加格式改变，需要做最小事实校正，
不能一边保留“八段/INT32”的事实描述，一边使用另一版本的准确性和PPA。
