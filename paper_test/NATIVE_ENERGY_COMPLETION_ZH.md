# 完整多头 SDPA 能量补测（2026-10-20）

## 正式定义

- 一次调用 = 原生 H 个 head 的 QK、softmax、PV；B=1，真实同源 Q/K/V。
- 主单位 mJ/次完整多头 SDPA，不是单头、单 tile、整步或整次生成。
- ASIC：同一 mapped 网表/DDC，625 MHz 目标，START 到最终输出 B 的全部活动。
- 用该窗口门级 SAIF 回读平均 IP 功率，再乘该窗口真实周期与 1.60 ns。
- 包含 IP 内 SRAM/寄存器/逻辑；排除外部 DRAM/PHY、主机及物理 CTS。
- GPU：共享 A6000 整卡能量含背景；与 ASIC IP 并列展示，不能称系统节能倍数。
